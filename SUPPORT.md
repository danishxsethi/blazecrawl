# Support

## Where to get help

* **Bugs** — open a GitHub issue using the bug template.
* **Feature requests** — open a GitHub issue using the feature template.
* **Questions / discussion** — GitHub Discussions (if enabled) or a
  well-scoped issue.

## What is a bug?

Something BlazeCrawl Core *claims to do* (see the README contract) that it does
not do, or does incorrectly/insecurely. Include a minimal reproduction and the
output of `/ready`.

## What is not a bug

* General web-scraping advice.
* Requests for managed proxies, hosted anti-bot, or enterprise features — those
  belong to the commercial BlazeCrawl Cloud, not this repository.
* Issues caused by not reading the README quickstart.

## Commercial support

This repository is community-supported on a best-effort basis. Paid support,
SLAs, and managed hosting are part of BlazeCrawl Cloud and are out of scope here.
